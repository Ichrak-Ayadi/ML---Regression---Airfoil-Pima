# Regression Models from Scratch

Implementation of linear and logistic regression algorithms applied to two real-world prediction problems:
aerodynamic noise prediction and medical diagnosis classification.

## Overview

This project demonstrates core machine learning fundamentals by implementing
regression algorithms manually, including cost functions, gradient descent, and
regularization, rather than relying on built-in library models.

### 1. Airfoil Self-Noise Prediction (Linear Regression)
Predicts the sound pressure level generated by airfoils based on physical and
aerodynamic properties: frequency, angle of attack, chord length, free-stream
velocity, and suction side displacement thickness.

**Highlights:**
- Custom implementation of gradient descent for least squares regression
- Cost function convergence analysis across different learning rates
- Cross-validation against the closed-form analytical (normal equation) solution
- Ridge regression with regularization parameter tuning
- Feature importance analysis based on coefficient magnitude

### 2. Diabetes Risk Classification (Logistic Regression)
Predicts diabetes risk from patient medical data (glucose levels, BMI, blood
pressure, age, and other diagnostic measurements).

**Highlights:**
- Logistic regression classifier implemented from scratch with gradient descent
- Decision boundary visualization
- Model evaluation via confusion matrix (accuracy, precision, recall, F1-score)
